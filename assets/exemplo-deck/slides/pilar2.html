Chamar a API e mostrar o texto não basta. O RAG é o exemplo mais pedido: a pergunta vira embedding, busca trechos parecidos num banco vetorial, esses trechos entram no prompt como contexto e o LLM responde fundamentado neles. Comente os demais conceitos: saídas estruturadas (JSON validado), tool calling (o modelo pede para executar uma função), gestão da janela de contexto, escolha de modelo por custo e qualidade, streaming da resposta.
