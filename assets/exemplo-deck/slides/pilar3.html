10 · MCP = Model Context Protocol, padrão aberto que conecta agentes a ferramentas

Aqui está a virada: agentes são desenhados para fazer coisas. Diante de um pedido, o modelo decide qual ferramenta chamar (buscar na web, consultar o banco, executar código, abrir o GitHub, ler arquivos), recebe o resultado e continua. O MCP (Model Context Protocol) é o padrão aberto que expõe essas ferramentas aos agentes; um estudo com mais de 177 mil ferramentas MCP mostrou 67% delas ligadas a desenvolvimento de software. Sugestão prática: montar um projeto com duas ou três ferramentas reais.
